# Setup (high level)

1. Cloudflare account (Free plan)
2. Create D1 database, R2 bucket, Queue
3. Deploy Workers with bindings
4. Run migrations
5. Set secrets (API tokens) via `wrangler secret`
6. Open Dashboard Setup Wizard (future)
7. Enable factory only after Test Connection passes

Users should not need to edit source or JSON by hand for normal operation.
